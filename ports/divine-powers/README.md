# Divine Powers — independent Sunrise prototype
Based on the gameplay descriptions of Hand of God 0.1.0 (onikoox, Forge 1.20.1). Original source and assets are not distributed, uploaded, or incorporated. Not an official port.
Native pin cac7bf64590fb38b4badee90f1f09848ce7f8daa, game 26.3. Creative-only initial sandbox build, main hand empty. U cycles, O casts, P alternate, I disables, /divine_powers help and named power commands. Raw server action protocol accepts exactly one byte; validates player mode, empty main hand, targets and line of sight. Other players and multipart bosses excluded.
Implemented candidate: matter/void damage + particles (not body disintegration or decals), telekinesis (velocity constraint and throw/alternate burst), thermal twin rays (no terrain melting), electric visual lightning + damage and weather, local mob AI pause/velocity slowdown (not true time dilation), personal time marker (position, health and world clock only, no world rollback) and clock acceleration, celestial charge/burst (not actual sun/moon relocation). Reality is explicitly unimplemented. No progression, wheel, held-key release integration, cinematic shaders, statues, destruction or full original fidelity yet.
Public APIs are sufficient for this first subset. Real native mixins require exact game source targets, correct bindings and function replacement compilation; do not add a dummy mixin just to claim support. Next targets: render sky bodies, post effects, server/entity tick routing, and bounded undo journal. Verify each target in pinned source before adding native.mixin.
Compile workflow checks exact API and runs unit tests; artifact only on successful check/test. No Android run claimed. Keep separate from RustPG and goblin workflows.
