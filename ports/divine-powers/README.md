# Hand of God — Sunrise personal adaptation
Original Hand of God 0.1.0 concept and Java mod by @onikoox. This isolated Rust project is independently implemented against Sunrise, without uploading or embedding the supplied JAR, original code, textures or sounds. Exact SDK: Preview 4 cac7bf64590fb38b4badee90f1f09848ce7f8daa, game 26.3.
U opens radial selection, O held activates, release throws gripped mobs or launches charged celestial projectile, P alternative, I clear. Rebind Controls in Starling Android; keyboard buttons work as mappings. Both survival and creative; spectators and player targets excluded. Commands /divine_powers help, /divine_powers next, cast, alt, release, clear, and named powers.
0.2.0 fixes all five observed SDK compile errors (host.mob and static key label) and adds radial screen, held input, projectile charge/flight/impact and a reversible bounded terrain wave. Natural full blocks only; journal in RAM, no persistent crash recovery, use backup/disposable world. Undo skips modified positions and retains unloaded positions. No biome rewriting yet. Matter/Void are damage plus particles, not original dissolution/shadow renderer. Heat uses two particle rays; no sliced models/tree felling. Local mob AI pause and velocity slowdown, not full world tick dilation. Time marker restores personal position/health/world clock, not other entities/inventory, no death rewind. Celestial projectile is not actual sky extraction. Lightning is not original flight/statue system. Still missing original sound/shaders and exact gesture/combination progression. Native mixin patch compilation not yet verified; no dummy patches. Public API preferred where it works. Unit tests + cargo check before source package. No Android runtime pass implied.

0.3.0: fixes early celestial release/cancel, charge expiry, one projectile per owner, line-of-sight projectile checks, damped telekinesis with captured hold distance and wall obstruction, alternate chain lightning (up to four visible additional mobs), alternate thermal burst and held thermal duration. Time alternate is toggled independently of cast release. Still an independent prototype, not an exact reproduction. No mixin or runtime validation claimed.
