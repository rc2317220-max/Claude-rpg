# Vision studio v2 — iterative art agent
The first run loaded the local model but failed because multi-view produced six images instead of seven. V2 takes eight individual compass shots and a top shot, sends the entire orbit sheet to the local VLM for defect identification, uses that diagnosis for the next edit, and audits each candidate and the final retained model. Final defects trigger another repair attempt; a budget cap or rejected edits never mean artistic approval.
Stages: bounded existing-cube changes and attached detail additions (reuse existing UVs); face-local painting; author and critique idle, walk, slam, sweep, roar, stagger, death motion studies (seven by default, reducible via workflow input); attack particle event binding and timing/locator review. Every rejected or failed mutating stage restores the last retained .bbmodel. Saves before/after sheets, raw plans, audit defects, reasons, and checkpoints. No arbitrary tool execution, shell, scripts, or repository writes by VLM. No external inference, API key, or guarantee of quality. VFX runtime rendering and smooth motion/physics are not proven by sampled poses or event metadata; human review and game tests required. The CPU runner and small model limit throughput and accuracy. Workflow budget 150 minutes; account Actions minutes apply.

Final geometry repair must also pass a fresh sampled-pose critique of every retained motion; otherwise it is rolled back. Reports distinguish unresolved defects from accepted changes and neither status represents artistic approval.
