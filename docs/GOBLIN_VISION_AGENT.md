# Experimental autonomous art refinement
Local Qwen2.5-VL 3B (quantized weights, pinned Hugging Face revision 5037fcf) and llama.cpp b6500, loopback only. No API key, no hosted inference, no repo-write permission on runner. GitHub Actions minutes still count against account quota. The agent receives the actual concept sheet plus seven labeled real Blockbench views, selects limited existing cube geometry adjustments, then compares before/after independently and rejects or rolls back regressions. It saves decisions, renders, candidate checkpoints, and a true 24-frame camera orbit video. It is not conscious and not a guarantee of visual quality. Initial scope is geometry refinement only, no new geometry, texture repaint, animation editing, arbitrary shell/eval, or runtime release. Protected attachment cubes cannot be edited by the agent. Human review required, even when the small VLM accepts a change. If all proposals fail, the run reports failure and keeps the baseline; no fake success. First execution is experimental; verify inference, camera framing, and visual judgments before widening permissions.
