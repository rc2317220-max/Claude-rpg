# Storm Gryphon advanced creature candidate
Existing rustpg:storm_gryphon definition uses 160 HP, movement speed .31, damage 15, zombie template. This candidate does not modify gameplay. New eagle/feline body, segmented tail, four-section wings, individually articulated primary feathers, front talons and rear hocks. Ground and flight clips authored separately; forward hit event gates and stance IK gates, independent saved BBModel replay, UV alpha QA, Rust export tests. Six attack definitions, VFX flipbooks and optional portrait-free boss skin. Offline previews do not prove actual flight, projectile AI, damage, HUD or Android performance. Assets remain isolated until runtime integration is validated. GitHub Actions only, no Codespaces required.

## Tempest art pass
The first candidate was technically valid but visually weak. The second pass targets a low forward predator profile, heavy chest and forelimbs, dark feather silhouette, narrow luminous eyes under a heavy brow, larger talons, swept long primaries, material-specific feather and fur painting, and a threat-display animation. The art sheet now shows the actual posed model in tight fixed still framing, head close-up and wings spread. Clips use fixed bounds per clip rather than a single overly distant camera. The death ground constraint evaluates transformed cube corners; remaining Blockbench overlap/animation warnings must still be reviewed. This is not yet a game runtime integration.
