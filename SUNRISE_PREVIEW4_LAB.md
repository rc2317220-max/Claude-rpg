## Agents
- Run Actions -> RustPG Sunrise Preview 4 laboratory. Three independent jobs: offline rig views, official Preview baseline, fresh RustPG candidate compile/test and native runtime.
- Never describe a queued workflow as passed. Inspect artifacts and check results.json. PASS requires measured outcome, FAIL an unmet assertion, BLOCKED missing telemetry, setup or unsupported API. The stable HMOD remains untouched. No upload of proprietary assets or account secrets. The endpoint token is redacted. No use of external public mod compilation for private RustPG.
- `tools/preview4_port.py` stages a mechanical public-API candidate, not a completed port. Read compiler errors; fix against the pinned source, not guessed signatures.
- `tools/sunrise_functional_lab.py`: uses real game control, checks server-profile message, V/Esc, HP deltas and hurt logs; calibrates vanilla effects separately. A staged lab-only fixture prepares a disposable profile and exposes authoritative stamina, window/cooldown, node ranks, points and power multipliers. Tests exercise real B/G/J/K/L input, purchases through Profile::buy, locked/duplicate refusal and effect expiry. This is not proof of UI purchase, parry damage prevention or live siphon healing; those need separate integration evidence. Never distribute the LAB-ONLY .smod as a playable release.
- `tools/creature_inspector.py`: `pip install numpy Pillow`, then `python tools/creature_inspector.py --output creature-inspection`. Reads generated Rust cube/bone/key definitions, uses actual PNG, rasterizes four angles and multiple poses. For arbitrary external model use `--model model.bbmodel --texture texture.png`. Authored UV mode supports cuboid Blockbench models with explicit unrotated face UVs, split Blockbench 5 group/outliner records, and ignores VFX locators. Does not emulate game tint, lighting, blended idle/walk or all Blockbench animation features. Runtime mode models the actual full-image-per-face policy (not a UV-correct approximation), which is the texture defect visible in RustPG. Never label the preview as a screenshot from the game.
- Skill tree references from user: Fatekeeper, radial graph, curved branching paths, different node sizes, luminous unlocked edges, pan/zoom. Current stable fixed pages are not the requested visual design; keep this as future UI acceptance criterion, no copy of proprietary images. 

## Preview rework candidate
`tools/sunrise_compat.py` ports retained command executors, reload closures, movement and damage hooks from exact Preview 4 declarations. `tools/sunrise_rpg_rework.py` adds single-purchase graph, drag/zoom, vanilla item primitives, optional touch menu, boss bar without portrait, measured server attack and armor, lighter defense scaling. `tools/creature_uv_atlas.py` creates independent per-face painted atlases for all twelve generated rigs. These are candidate transformations only: no stable source or save is overwritten. Current meshes are reused; geometry refinement, combat-effect audit, save migration, true device verification remain acceptance requirements.
