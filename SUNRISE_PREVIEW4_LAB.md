- `tools/creature_inspector.py`: `pip install numpy Pillow`, then `python tools/creature_inspector.py --output creature-inspection`. Reads generated Rust cube/bone/key definitions, uses actual PNG, rasterizes four angles and multiple poses. For arbitrary external model use `--model model.bbmodel --texture texture.png`. Authored UV mode supports cuboid Blockbench models with explicit unrotated face UVs. Does not emulate game tint, lighting, blended idle/walk or all Blockbench animation features. Runtime mode models the actual full-image-per-face policy (not a UV-correct approximation), which is the texture defect visible in RustPG. Never label the preview as a screenshot from the game.
