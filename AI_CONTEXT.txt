RUSTPG AI CONTEXT
=================

Este arquivo existe para ferramentas de IA que conseguem abrir arquivos individuais do GitHub, mas não conseguem listar pastas.

VERSÃO
------
RustPG 6.0.0-alpha
Starling/Horizon 0.9.0
Game 26.3
Horizon pin: ff303502a4f7982551a0e0d3622d9268efe9e829
Pacote canônico: releases/RustPG.hmod

ARQUITETURA
-----------
project/src/lib.rs
  Integra todos os hooks da API pública, perfil, UI, dano, payloads, criaturas e Fendas.

UI / HUD
  rustpg_ui_window.rs, rustpg_ui_layout.rs, rustpg_ui_system.rs,
  rustpg_ui_widgets.rs, rustpg_ui_input.rs, rustpg_ui_animation.rs,
  rustpg_hud.rs, rustpg_target_hud.rs, rustpg_boss_ui.rs,
  rustpg_bestiary.rs, rustpg_view.rs.

COMBATE
  rustpg_action_combat.rs define timings por família de arma.
  rustpg_guard.rs controla parry/dodge/perfect windows.
  rustpg_combat_pipeline.rs resolve dano autoritativo.
  rustpg_combo.rs e rustpg_hitboxes.rs só trabalham com golpes confirmados.

FENDAS / DUNGEONS
  rustpg_rifts.rs define Rank E-S, Ressonância, salas, anomalias,
  geração determinística, ondas, boss e avaliação S-D.
  lib.rs abre RuntimeGenerator::Void em rustpg:rift/<id>, constrói,
  teleporta, gerencia a run, retorna o jogador e apaga a instância.

CRIATURAS
  rustpg_native_entities.rs registra renderers/AI.
  scripts/generate_creatures.py gera texturas, JSON e
  rustpg_creatures_generated.rs.
  O catálogo próprio atual possui 12 criaturas.

PROGRESSÃO
  rustpg_profile.rs é o save autoritativo.
  rustpg_nodes.rs + rustpg_attributes.rs definem Skill Tree/stats.
  rustpg_scaling.rs define tiers/HP/scaling de mobs.
  Perfil também persiste Ressonância, clears e melhores ranks/notas.

REGRAS QUE NÃO PODEM REGREDIR
-----------------------------
- sem hnmod/mixins/whole-game Compile;
- sem quests/dailies;
- sem Block Bar interpolada fingindo precisão de 1%;
- V é o atalho da UI;
- dungeons não exigem chave comum;
- combate e recompensas são decididos no servidor;
- não copiar assets do JAR de referência;
- não inventar chamadas da API Horizon: confirmar no SDK e compilar.

VALIDAÇÃO
---------
bash scripts/validate.sh
cargo check --manifest-path project/Cargo.toml --lib
cargo test --manifest-path project/Cargo.toml --lib
