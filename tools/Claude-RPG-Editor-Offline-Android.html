Claude RPG — Editor offline

Funciona no navegador Android, sem internet. Crie e valide árvores, missões e scripts de XP. Os arquivos .json de missões/árvores são projetos editáveis e não são carregados automaticamente pelo mod; o script .crpgx é compatível com a VM existente.
